feat: Implement messaging system with conversation-based encryption

## Overview
This commit introduces a messaging system with conversation-based AES-256-CBC encryption
and real-time updates via Socket.io.

## Major Features Added
- **Conversation Encryption**: AES-256-CBC encryption with deterministic key derivation using CryptoJS
- **Real-time Messaging**: Socket.io integration for live message updates
- **Message Management**: Create conversations, send messages, and view message history
- **User Interface**: Complete messaging UI with conversation list and chat interface

## Technical Implementation
- Added crypto module with CryptoJS integration for AES-256-CBC encryption
- Implemented conversation-based key derivation for secure messaging
- Created messaging services with API endpoints for conversations and messages
- Built Socket.io context for real-time message delivery
- Added messaging components with proper TypeScript types

## Breaking Changes
None - this is a new feature addition
